# Schedule++ · 安卓课程表与日程

一个以课程表为主页的个人学习安排 App：查看课程、记录作业/报告/考试等截止任务，并设置本地提醒。

**Android 8.0+ · 原生 Android / Java · 本地保存 · 无账号 · 无联网权限**

## 下载与安装

前往 **[最新版本下载](https://github.com/yu2660/schedule-plus-plus/releases/latest)**，展开页面底部的 **Assets**，下载以 `.apk` 结尾的安装包。`Source code` 是源码，不能直接安装。

- 已发布版本：**[v0.4.2](https://github.com/yu2660/schedule-plus-plus/releases/tag/v0.4.2)**。
- [直接下载 v0.4.2 APK](https://github.com/yu2660/schedule-plus-plus/releases/download/v0.4.2/SchedulePlusPlus-0.4.2-personal.apk)。
- 将 APK 下载到手机后打开；如系统询问，仅向用于安装的浏览器或文件管理器临时允许“安装未知应用”，安装后可以关闭。
- 使用相同签名的新版可覆盖升级，升级前建议导出备份。若提示签名不一致，请先备份，避免直接卸载造成数据丢失。
- Release 附带 `SHA256SUMS.txt`，可用于核对下载文件的完整性。

本项目尚未上架应用商店。请只从本仓库 Releases 获取安装包，不需要提供教务账号或密码。

## 本次升级

0.4.2 采用默认「清爽校园」外观：支持纯色、渐变、相册图片背景，四种课程卡片样式，以及跟随系统、浅色和深色模式。相册背景可以拖动、缩放和旋转后裁剪，遮罩帮助保持文字清晰。背景色和渐变起点、终点直接通过色板或 #RRGGBB 输入选择，显示实际效果预览；课程配色显示色块。按钮保留间距并加强浅色模式的对比，课表日期范围固定单行。

课程详情改为可展开的底部面板，上滑或点击顶部展开，下滑关闭；周次默认合并显示，点击可展开完整列表。日程卡片突出标题、课程和截止时间，点击查看完整说明，右滑完成后可在 6 秒内撤销，长按可编辑、修改截止时间或删除。撤销提示超时只移除提示，避免刷新整个页面打断滑动。原有课表定位、全屏总览、学期复用与本地提醒继续保留。

外观滑块提供实时百分比与就近效果预览：选择「半透明卡片」后可调整不透明度，选取相册背景后可调整遮罩。不适用时显示启用提示。外观设置中不再提供三个独立的渐变预设按钮。

升级前建议导出旧版备份。新版支持 V1/V2 备份迁移；新版导出的 V3 备份包含模板与显示偏好，无法在 0.2.3 中恢复。

## 主要功能

- **周课程表与全屏总览**：切换教学周、标记当天、连续节次合并、提示课程重叠。普通课表采用方向锁定和固定节次栏；全屏总览完整适配全部节次，支持横竖屏、双指缩放、一键适配和周次切换。在本周隐藏“回到本周”，其他周显示；学期外不显示。进入课表时自动定位今天和正在上的课，连续课块尽量居中；没有正在上的课时定位相应节次。
- **多学期与配置复用**：自定义名称、备注、首周周一、1–60 教学周和每日 1–24 节。新学期可复用已有作息，选择是否复制课程，预览后确认；不复制旧任务和提醒。
- **灵活排课与复制**：指定星期、节次及任意教学周，可快捷选全部/单双周；复制课程或上课时段，新增时段沿用上一时段的选项后再调整。
- **课程关联任务**：点击课程查看未完成任务，快速添加作业、报告或考试，也能添加个人任务。日期支持今天、明天、一周后，具体截止时间可选。
- **任务模板**：提供作业、实验报告和考试模板，也可新建、修改、删除模板，复用标题前缀、说明和相对提醒习惯。模板不保存课程和具体日期。
- **日程与任务交互**：按已逾期、今天、明天、之后分组并显示相对时间。点击卡片查看完整说明，右滑或勾选完成，6 秒内可撤销；长按编辑、快捷修改截止时间或删除，保留完成记录。
- **本地提醒**：自定义提醒或选择截止前一天、一小时；相对提醒随截止日期和时间调整。修改、完成或删除任务后同步调整提醒。
- **显示与交互偏好**：选择是否显示周末、教师、地点和时间；课程名突出、当天列标记、正在上课细边框。课程详情及快捷操作从底部打开，长表单独立显示并固定保存/取消按钮。
- **外观与背景**：默认清爽校园；纯色、渐变或从系统文件选择器选择相册图片，支持裁剪、旋转及遮罩。课程卡片提供柔和彩色、左侧色条、半透明和描边；支持跟随系统、浅色、深色。外观设置与裁剪图片仅保存在本机，不进入 JSON 备份。
- **备份与恢复**：系统文件选择器导出 JSON，恢复前校验和预览；包含全部学期、模板与显示偏好，支持旧版本备份迁移。数据保存在设备，无需登录。

## 快速开始

1. 进入“设置 → 学期与作息设置”，配置学期起始日期、教学周数和每日作息。
2. 点击右下角“＋”添加课程，选择对应的星期、节次和教学周。
3. 点击课程进入详情，再添加关联任务；也可以用“＋”添加个人任务。
4. 在“日程”页按截止时间查看全部未完成任务，完成后勾选。
5. 需要提醒时选择提醒时间，并允许系统通知；需要更准时的提醒时，在设置中检查准时提醒权限及系统省电限制。
6. 点击课表顶栏的“总览”，可完整查看、缩放及切换周次；本周隐藏“回到本周”，其他周显示。
7. 在“设置 → 课表与任务偏好”选择显示内容或管理模板；新建学期时可预览并复用旧学期的配置。
8. 在“设置 → 外观与背景”调整背景、课程卡片和深浅色模式。
9. 定期导出备份，尤其在升级、卸载或换手机之前。

## 权限与隐私

App 无联网权限，无广告或统计 SDK。仅使用通知、开机接收及准时提醒相关权限，系统文件选择器负责备份文件的读写及背景图片选择，不申请整个存储空间的访问权限。

课程、任务与裁剪后的背景图片保存在应用本地目录。所选图片有大小和像素上限，裁剪后重新编码保存，不保留原图元数据；不申请整个相册权限。外观设置及背景图片不包含在 JSON 备份中。导出的备份是**明文 JSON**，可能包含课程、地点、任务及备注，请自行妥善保存，不要提交到公开 Issues。卸载应用或清除应用数据会删除本地记录。

## 从源码构建

使用 JDK 17、Android SDK 35 和 Android SDK Build Tools 35.0.0，在 Android Studio 打开本目录；通过 `ANDROID_HOME` 或本地 `local.properties` 指定 SDK。Gradle Wrapper 固定 8.9，AGP 固定 8.7.3，运行时仅依赖 Android 平台 API。

```powershell
# Windows；macOS/Linux 使用 ./gradlew
.\gradlew.bat assemblePersonal
```

自行构建的签名通常与 Releases 不同，不保证能相互覆盖安装。签名密钥、SDK、缓存和生成的安装包均不提交到源码仓库。
